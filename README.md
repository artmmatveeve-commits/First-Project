# First-Project. Electronic library / Library catalog
Проект для создание электронной библиотеки на языке программирование С++

Описание:
Консольное приложение на С++, разработанное в качестве первого проекта. Программа представляет собой автоматизированную систему для управления библиотечным фондом, учета читателей и контроля выдачи книг. 

В основе проекта лежит концепция создания единого цифрового пространства для библиотекаря. Система решает проблему ручного учета, исключает потерю данных о выданных книгах и позволяет мгновенно получать аналитику о состоянии библиотечного фонда. 

Программа разделяет весь книжный фонд на категории и ведет учет двух ключевых сущностей: **Книги** (разных типов) и **Читатели** (пользователи библиотеки). Между ними реализована логическая связь (процесс выдачи и возврата литературы).

Функционал системы:
1. Управление библиотечным фондом (CRUD)
* **Добавление новых поступлений:** возможность в интерактивном режиме зарегистрировать книгу, указав её тип (художественная/учебная).
* **Списание литературы:** удаление утерянных или ветхих книг из общей базы данных по уникальному инвентарному номеру (ID/ISBN).
* **Модификация данных:** изменение текущего количества доступных экземпляров при поступлении новых тиражей.

2. Поисково-аналитический модуль
* **Многокритериальный поиск:** быстрый поиск книги по точному совпадению названия, фамилии автора или уникальному международному номеру ISBN.
* **Фильтрация по категориям:** вывод на экран только учебной литературы для конкретного факультета или книг определенного литературного жанра.
* **Проверка доступности:** визуальное отображение статуса книги (сколько штук на складе, доступны ли они для выдачи прямо сейчас).

3. Модуль обслуживания читателей (Интерактивное взаимодействие)
* **Регистрация читательских билетов:** ведение базы данных посетителей (ФИО, номер билета, контакты).
* **Выдача книг на руки:** привязка книги к конкретному читателю. При этом система автоматически уменьшает количество доступных экземпляров в общем каталоге.
* **Возврат книг:** снятие книги с профиля читателя и возвращение её в доступный фонд библиотеки.
* **Контроль должников:** функция вывода списка читателей, которые на данный момент удерживают книги на руках.

4. Подсистема хранения данных (Персистентность)
* **Десериализация при старте:** во время запуска программа проверяет наличие файла базы данных (`library_db.txt`), считывает строки, корректно распознает типы объектов и восстанавливает структуру в оперативной памяти.
* **Сериализация при выходе:** при завершении работы через меню все изменения (новые книги, выданные билеты, измененное количество) перезаписываются в файл, что гарантирует сохранность данных между сессиями.

Техническая реализация:

Проект разработан в строгом соответствии с принципами объектно-ориентированного программирования:

* **Инкапсуляция:** Все критически важные свойства классов (названия, ID, личные данные читателей) объявлены в секции `protected` или `private`. Доступ к ним и их валидация осуществляются через public-методы (геттеры и сеттеры).
* **Иерархия наследования:** 
  * Создан абстрактный (или базовый) класс `Book`.
  * От него унаследован класс `FictionBook` (добавлены поля: *жанр*, *возрастной ценз*).
  * От него унаследован класс `EducationalBook` (добавлены поля: *предметная область*, *рекомендовано для вуза/школы*).
* **Полиморфизм:** Использование виртуальных функций (например, `virtual void display()` и `virtual void serialize()`). Это позволяет хранить разнородные объекты (и романы, и учебники по физике) в едином динамическом массиве `std::vector<Book*>` и корректно обрабатывать их в циклах.
* **Безопасность и управление памятью:** Реализован корректный деструктор управляющего класса для очистки кучи (`heap`) от динамически созданных объектов, что предотвращает утечки памяти (`memory leaks`). Применение стандартных строк `std::string` гарантирует защиту от переполнения буфера.

Требование и запуск:
* **Язык:** C++ (поддерживает стандарты C++11 и выше).
* **Среда разработки:** Visual Studio, CLion, Xcode или Code::Blocks.
