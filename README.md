# Virst Project. Cramer's rule application.

> Мой первый проект я собираюсь написать на С++. Основная задумка, чтобы пользователь вводил систему линейных алгебраических уравнений, а программа определяла, сколько в ней неизвестных переменных, вычисляла их и выводила на экран. Использовать программа будет метод Крамера (возможно метод поменяется в процессе углубления в материал). Если главный определитель detA будет равен нулю, то программа должна будет вычислить, имеет система бесконечное количество решений или не имеет решений вовсе и выводит сообщение в консоль.

> Для начала я написал программу, которая запрашивает у пользователя в консоли систему линейных алгебраических уравнений с двумя неизвестными, находит их с помощью метода Крамера и выводит в консоль. В случаи, если главный определитель detA будет равен нулю, программа выводит сообщение. Весь код представлен ниже:

## Исходный код программы 
```cpp
#include <iostream>
#include <string>

int main()
{
	setlocale(LC_ALL, "Rus");

	int const ROWS = 2;
	int const COLS = 3;
	double x1, x2;

	int sustem2X2[ROWS][COLS];
	std::string ans[COLS]{ "коэффициент x1 ", "коэффициент x2 ", "свободный член " };

	for (int i{ 0 }; i < ROWS; i++)
	{
		for (int j{}; j < COLS; j++)
		{
		    std::cout << "Введите " << ans[j] << i + 1 << "-го уравнения: ";
			std::cin >> sustem2X2[i][j];
		}
	}

	int detA = sustem2X2[0][0] * sustem2X2[1][1] - sustem2X2[0][1] * sustem2X2[1][0];

	if (detA == 0)
	{
		std::cout << "Система имеет бесконечное количество решений или не имеет решений вовсе! ";
	}
	else
	{
		x1 = (sustem2X2[0][2] * sustem2X2[1][1] - sustem2X2[0][1] * sustem2X2[1][2]) / detA;
		x2 = (sustem2X2[0][0] * sustem2X2[1][2] - sustem2X2[0][2] * sustem2X2[1][0]) / detA;

		std::cout << "Корни системы равны: " << std::endl << "x1 = " << x1 << std::endl << "x2 = " << x2;
	}

	return 0;

}
```

> Далее я решил расширить свою программу, добавив выбор пользователю сколько будет неизвестных. Для этого выводиться строчка в консоль. Если было выбрано 2 или 3 переменных, то программа решала систему линейных алгебраических уравнений методом Крамера. Но если пользователь выберет 4 (пока что это мое максимальное количество неизвестных, которое я могу найти), то программа переходит к методу Гаусса. Сделана это потому что метод Крамера рассчитан для маленьких систем, если определитель матрицы будет 4 порядка, то метод Крамера становиться либо невозможным, либо очень сложным.

> Я разбил метод Крамера на две функции типа void. Sustem2X2 при вызове решает систему уравнений с двумя неизвестными, а sustem3X3 с тремя. Вот как обе функции выглядят в редакторе:

## Исходный код функций метода Крамера
```cpp
#include <iostream>
#include <string>

void sustem2X2()
{
	int const ROWS = 2;
	int const COLS = 3;
	double x1, x2;

	std::string ans[COLS]{ "коэффициент x1 ", "коэффициент x2 ", "свободный член " };

	{
		for (int j{}; j < COLS; j++)
		{

	int detA = sustem2X2[0][0] * sustem2X2[1][1] - sustem2X2[0][1] * sustem2X2[1][0];

	if (detA == 0)
	{
		std::cout << "Система имеет бесконечное количество решений или не имеет решений вовсе! ";
	}
	else
	{
		x1 = (sustem2X2[0][2] * sustem2X2[1][1] - sustem2X2[0][1] * sustem2X2[1][2]) / detA;
		x2 = (sustem2X2[0][0] * sustem2X2[1][2] - sustem2X2[0][2] * sustem2X2[1][0]) / detA;

		std::cout << "Корни системы равны: " << std::endl << "x1 = " << x1 << std::endl << "x2 = " << x2;
	}
}

void sustem3X3()
{
	int const ROWS = 3;
	int const COLS = 4;
	double x1, x2, x3;

	int sustem3x3[ROWS][COLS];
	std::string ans[COLS]{ "коэффициент x1 ", "коэффициент x2 ", "коэффициент x3 ", "свободный член " };

			std::cout << "Введите " << ans[j] << i + 1 << "-го уравнения: ";

	int detA = (sustem3x3[0][0] * sustem3x3[1][1] * sustem3x3[2][2] + sustem3x3[0][1] * sustem3x3[1][2] * sustem3x3[2][0] + sustem3x3[0][2] * sustem3x3[1][0] * sustem3x3[2][1]) -

		std::cout << "Система имеет бесконечное количество решений или не имеет решений вовсе! ";

		x2 = ((sustem3x3[0][0] * sustem3x3[1][3] * sustem3x3[2][2] + sustem3x3[0][3] * sustem3x3[1][2] * sustem3x3[2][0] + sustem3x3[0][2] * sustem3x3[1][0] * sustem3x3[2][3]) -
			(sustem3x3[0][2] * sustem3x3[1][3] * sustem3x3[2][0] + sustem3x3[0][0] * sustem3x3[1][2] * sustem3x3[2][3] + sustem3x3[0][3] * sustem3x3[1][0] * sustem3x3[2][2])) / (double)detA;
```

> Для того, чтобы моя программа работала, не хватает только функции main, в которой я реализую выбор количества неизвестных и с помощью цикла switch выбор функции метода Крамера. Вот так вот выглядит функция main:

## Исходный код функции main
```cpp
#include <iostream>
#include <string>

int main()
{
	setlocale(LC_ALL, "Rus");

	int n;
	std::cout << "Введите количество переменных в системе уравнений: ";
	std::cin >> n;

	switch (n)
	{
	case 2:
		sustem2X2();
		break;
	case 3:
		sustem3X3();
		break;
	default:
		std::cout << "Методом крамера не решить данную систему: ";
		break;
	}
	return 0;
}
```
