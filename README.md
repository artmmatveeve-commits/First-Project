# Virst Project. Cramer's rule application.

> Мой первый проект я собираюсь написать на С++. Основная задумка, чтобы пользователь вводил систему линейных алгебраических уравнений, а программа определяла, сколько в ней неизвестных переменных, вычисляла их и выводила на экран. Использовать программа будет метод Крамера (возможно метод поменяется в процессе углубления в материал). Если главный определитель detA будет равен нулю, то программа должна будет вычислить, имеет система бесконечное количество решений или не имеет решений вовсе и выводит сообщение в консоль.

> Для начала я написал программу, которая запрашивает у пользователя в консоли систему линейных алгебраических уравнений с двумя неизвестными, находит их с помощью метода Крамера и выводит в консоль. В случаи, если главный определитель detA будет равен нулю, программа выводит сообщение. Весь код представлен ниже:

## Исходный код программы 
```cpp
#include <iostream>
#include <string>

int main()
{
	setlocale(LC_ALL, "Rus");

	int const ROWS = 2;
	int const COLS = 3;
	double x1, x2;

	int sustem2X2[ROWS][COLS];
	std::string ans[COLS]{ "коэффициент x1 ", "коэффициент x2 ", "свободный член " };

	for (int i{ 0 }; i < ROWS; i++)
	{
		for (int j{}; j < COLS; j++)
		{
		    std::cout << "Введите " << ans[j] << i + 1 << "-го уравнения: ";
			std::cin >> sustem2X2[i][j];
		}
	}

	int detA = sustem2X2[0][0] * sustem2X2[1][1] - sustem2X2[0][1] * sustem2X2[1][0];

	if (detA == 0)
	{
		std::cout << "Система имеет бесконечное количество решений или не имеет решений вовсе! ";
	}
	else
	{
		x1 = (sustem2X2[0][2] * sustem2X2[1][1] - sustem2X2[0][1] * sustem2X2[1][2]) / detA;
		x2 = (sustem2X2[0][0] * sustem2X2[1][2] - sustem2X2[0][2] * sustem2X2[1][0]) / detA;

		std::cout << "Корни системы равны: " << std::endl << "x1 = " << x1 << std::endl << "x2 = " << x2;
	}

	return 0;

}
```
